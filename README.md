Survey data (not included in this repository)

The primary survey dataset (australia.csv) is too large to host here. It is sourced from the Imperial College London YouGov Covid-19 Behaviour Tracker Data Hub:


Data repository: https://github.com/YouGov-Data/covid-19-tracker
Project page: https://www.imperial.ac.uk/centre-for-health-policy/our-work/our-response-to-covid-19/covid-19-behaviour-tracker/


To reproduce the analysis, download the Australia data from the repository above, save it as australia.csv, and place it in the working directory alongside the other files listed here.

How to reproduce


Download australia.csv as described above.
Run Phase_two.R with all CSV files and images in the working directory..
Knit Report_Mahesh_Yash.Rmd in RStudio (or via rmarkdown) to produce the final PDF.
